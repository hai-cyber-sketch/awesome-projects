## Status Labels

- **High priority** — especially worth exploring soon
- **Want to try** — saved for hands-on testing
- **Testing** — currently evaluating
- **Using** — actively useful in a real workflow
- **Learning resource** — primarily a course or curriculum
- **Reference** — mainly for lookup or occasional use
- **Watching** — worth following, not an immediate install
- **Archived** — retained for reference but no longer active
