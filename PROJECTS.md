## 🤖 AI Agents & Agent Engineering

### [browser-use/jev-ultrafast](https://github.com/browser-use/jev-ultrafast)

Fast browser agent built around a dynamic indexed action space. It observes structured page controls, chooses actions such as click/type/select, and drives a real Chrome browser through Browser Harness.

**Useful for:** browser automation, website interaction, agent workflows, web task automation  
**Tags:** `Browser Agent` `Automation` `Chrome` `Agent`  
**Status:** Want to try

---

### [zai-org/ZCode](https://github.com/zai-org/ZCode)

An AI coding workspace that combines desktop, web and agent-oriented development workflows. It is especially interesting as an open-source coding-agent environment.

**Useful for:** AI-assisted programming, coding agents, desktop AI workspace  
**Tags:** `AI Coding` `Agent` `Developer Tools`  
**Status:** Watching

---

### [tigerless-labs/agent-memory](https://github.com/tigerless-labs/agent-memory)

A local memory layer for AI agents, designed to persist useful information across sessions without requiring a hosted vector database.

**Useful for:** long-term agent memory, shared context, local retrieval  
**Tags:** `Agent Memory` `MCP` `Knowledge`  
**Status:** Want to try

---

### [okf-memory/okf-agent-memory](https://github.com/okf-memory/okf-agent-memory)

Git-native persistent memory for AI agents based on structured plain-text knowledge. Includes local retrieval and an MCP server.

**Useful for:** persistent project knowledge, agent memory, auditable Git-based knowledge stores  
**Tags:** `Agent Memory` `MCP` `Git` `Knowledge Base`  
**Status:** Want to try

---

### [bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book)

《深入理解 AI Agent：设计原理与工程实践》. A systematic open-source book centered on the idea:

> Agent = LLM + Context + Tools

It covers Agent Memory, context engineering, MCP, RAG, multi-agent systems, multimodal agents and engineering practice, with many accompanying experiments.

**Useful for:** systematically learning AI Agent architecture and engineering  
**Tags:** `AI Agent` `MCP` `RAG` `Memory` `Context Engineering`  
**Status:** High priority

---

### [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach)

A toolkit that gives AI agents practical access to internet sources such as X/Twitter, Reddit, YouTube, GitHub, Bilibili, Xiaohongshu and ordinary web pages.

**Useful for:** agent web access, search, content retrieval, social-media research  
**Tags:** `AI Agent` `Web` `Search` `Scraping` `MCP`  
**Status:** High priority

## Status Reference

- **High priority** — especially worth exploring soon
- **Want to try** — saved for hands-on testing
- **Testing** — currently evaluating
- **Using** — actively useful in a real workflow
- **Learning resource** — primarily a course or curriculum
- **Reference** — mainly for lookup or occasional use
- **Watching** — worth following, not an immediate install
- **Long-term learning** — large curriculum requiring sustained study
- **Reading resource** — primarily saved for reading or language practice
- **Archived** — retained for reference but no longer active
